# Biological inspiration
Status: design metaphor, not a biological model.

NOAA describes killer whales as social animals with population-specific social organization, learned behaviors, and cooperative hunting. Social patterns vary; no single pod description applies universally. See [NOAA Fisheries: Killer Whale](https://www.fisheries.noaa.gov/species/killer-whale), consulted 2026-10-23.

| Inspiration | Proposed engineering translation | Limit of analogy |
| --- | --- | --- |
| Cooperative activity | Agents take complementary roles toward a shared objective | LLM agents do not share animal cognition or intent |
| Learned behavior | Reviewed procedures persist across tasks | Retrieved text is not equivalent to biological learning |
| Social coordination | Bounded messages and evidence handoffs | Communication can amplify correlated errors |
| Group identity | Scoped pod state and explicit membership | Software pods are temporary contracts, not kinship groups |

Dynamic software pod formation is an engineering choice. It is not a claim that killer-whale pods are freely assembled task queues. ORCA does not infer algorithmic effectiveness from animal behavior.

The metaphor suggests questions: when does specialization help, how much communication is useful, and which lessons transfer? Controlled experiments must answer them. Avoid claims of emergent intelligence, consciousness, evolutionary optimization, or biological fidelity without evidence.

The name is illustrative and does not imply endorsement by conservation or scientific organizations.
